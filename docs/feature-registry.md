# Feature registry

Generated by `node scripts/count-registry.mjs`. The count is derived from
the repository — pages a visitor can reach, functions the database exposes,
policies that decide who sees what, console screens, domain rules, plugin
flags and edge endpoints — so it describes the commit it was run on rather
than the commit somebody remembers.

Nothing is counted twice. A page is not also counted as the component that
renders it; an RPC is not also counted as the policy that guards it; a test
is not a feature.
