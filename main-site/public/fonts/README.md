# Bengali web font

`noto-sans-bengali.woff2` is a Bengali-script subset of the SIL Open Font
License 1.1 Noto Sans Bengali variable font distributed in
`corporate-kit/src/pdf/fonts/NotoSansBengali.b64`. Its original source is
Google Fonts commit `73b3937823dfe9d7f4cdcc0b2399a1f06940430d`, decoded
SHA-256 `dcd42978094e584a849c84a51450eeac40c8826057d566ea6d4b9627a403a05a`.
The subset SHA-256 is `f4ea4b42ab0d692d62935c714c7c6a4de6089e66a411c81104dea777ad3cb036`.

It was generated with fontTools 4.68.0 using `pyftsubset`, `--flavor=woff2`,
`--layout-features='*'`, and Unicode ranges U+0964–0965, U+0980–09FF, U+1CD0–1CFF,
U+200C–200D, U+20B9, U+25CC, U+A8E0–A8FF and U+11B00–11B09. Name records,
variable axes, layout tables, .notdef and recommended glyphs were retained.
`OFL-NotoSansBengali.txt` is the license. The font is served locally and loaded
only when a character in the subset is needed.
