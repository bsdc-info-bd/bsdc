# BSDC Android App

- **Package**: `bd.info.bsdc.app`
- **App name**: BSDC
- **Firebase project**: `bsdc-bd`
- **Delivered in**: Response 19 of the 20-response build plan

Capacitor shell around the deployed main site (https://www.bsdc.info.bd) with a
native status bar, splash screen, deep links (`https://www.bsdc.info.bd/*` and
`bsdc://`), native Google sign-in and FCM push delivered to the system tray even
when the app is closed or the device is locked.

## Plugins

`@capacitor/core`, `@capacitor/cli`, `@capacitor/android`, `@capacitor/app`,
`@capacitor/status-bar`, `@capacitor/splash-screen`, `@capacitor/browser`,
`@capacitor-firebase/messaging`, `@capacitor-firebase/authentication`.

## Build

Launcher icons and splash screens are generated by
`scripts/generate-brand-assets.mjs`. Signed release AABs are produced by GitHub
Actions using the `ANDROID_KEYSTORE*` repository secrets. `google-services.json`
is supplied through CI and is never committed.
